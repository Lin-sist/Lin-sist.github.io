### 2.1 DatabaseConnector.java
这个类是整个系统与数据库通信的"桥梁"，负责建立JDBC连接。
- 首先导入三个包：Connection负责与数据库对接和后续SQL操作；DriverManager用于加载数据库驱动并通过getConnection()方法创建与数据库的连接；SQLException负责抛出SQL异常。
- 接着先定义数据库的URL，用户名和密码，用于连接数据库；定义getConnection方法用于获取数据库连接对象。
- 使用Class.forName显式加载 MySQL 驱动程序；加载驱动后，DriverManager才能识别`jdbc:mysql://`协议（jdbc协议代表使用MySQL驱动）；最后调用DriverManager的静态方法建立数据库连接（一个Connection对象，用于执行SQL语句），这样就顺利连接到了数据库。
- 代码中使用了try-with-resources 语法，它可以在代码执行结束后自动关闭数据库连接，避免资源泄漏；而throws SQLException 将异常抛出，交由调用者统一处理。

### 2.1.1 代码演示
```java
package com.studentmanagement;      //DatabaseConnector.java

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

//封装管理数据库的连接
public class DatabaseConnector {

    private static final String URL = "jdbc:mysql://localhost:3306/school";
    private static final String USER = "root";
    private static final String PASSWORD = "123456";

    public static Connection getConnection() throws SQLException {  //负责连接到MySQL数据库
        try {
            // 加载 MySQL 驱动程序
            Class.forName("com.mysql.cj.jdbc.Driver");
            // 返回数据库连接（一个Connection对象，用于执行SQL语句）
            return DriverManager.getConnection(
                    "jdbc:mysql://localhost:3306/school",
                    "root",
                    "123456"
            );
        } catch (ClassNotFoundException e) {
            throw new SQLException("MySQL driver not found", e);
        }
    }
}

//java.sql.Connection包，用于创建数据库连接，后期创建PreparedStatement的对象执行来SQL命令
//java.sql.DriverManager包，用于加载MySQL驱动，提供getConnection方法连接数据库
//java.sql.SQLException包，用于当数据库操作错误时抛出数据库的异常
```

### 2.2 Student.java
这个类主要用于封装学生的信息，以及增删查改等具体数据库操作方法。
- 首先导入三个包：java.sql包下所有类（Statement, PreparedStatement, ResultSet等），用于JDBC操作；导入ArrayList，用于存储学生列表；导入List接口，用于定义返回类型；
- 定义Student类，用于表示学生实体及其数据库操作；定义学生实体的四个属性；定义有参构造方法，用于创建Student对象实例。
- 定义Getter方法，这些getter方法会在数据库操作中使用；重写Object类的toString方法，方便调试时打印对象信息。
- 最后分别定义增删查改方法。
- 特别注意在“增添学生”这个方法中，定义query字符串只有三个占位符，因为id在建表时设置为了自增主键，我们不需要再去设置id，按顺序设置SQL占位符的值。索引从1开始（不是0）。`executeUpdate()`用于执行INSERT/UPDATE/DELETE语句，返回受影响的行数。
- 在“查询学生”这个方法中，首先用List存储查询结果，初始为空，后面的ArrayList代表具体实现；`ResultSet`为结果集对象，像一个指针，可以逐行遍历查询结果；后面的while语句遍历结果集，将每一行数据转换为Student对象，添加到列表中。


### 2.2.1 代码演示
```java
package com.studentmanagement;      //Student.java

import java.sql.*;
import java.util.ArrayList;
import java.util.List;

//用于封装学生信息和数据库交互功能
public class Student {
    private int id;
    private String name;
    private int age;
    private String major;

    //用于创建学生对象实例（有参构造方法）
    public Student(int id, String name, int age, String major) {
        this.id = id;
        this.name = name;
        this.age = age;
        this.major = major;
    }

    //用于获取学生对象属性值
    public int getId() { return id; }
    public String getName() { return name; }
    public int getAge() { return age; }
    public String getMajor() { return major; }

    //重写toString方便打印学生对象信息
    @Override
    public String toString() {
        return String.format("Student[id=%d, name='%s', age=%d, major='%s']", id, name, age, major);
    }

    //增
    public static void insertStudent(Connection connection, Student student) throws SQLException {
        String query = "INSERT INTO students (name, age, major) VALUES (?, ?, ?)";
        try (PreparedStatement ps = connection.prepareStatement(query)) {
            ps.setString(1, student.getName());
            ps.setInt(2, student.getAge());
            ps.setString(3, student.getMajor());
            ps.executeUpdate(); //执行插入
        }
    }
    //删
    public static boolean deleteStudentById(Connection connection, int id) throws SQLException {
        String query = "DELETE FROM students WHERE id = ?";     //根据id删除学生
        try (PreparedStatement ps = connection.prepareStatement(query)) {
            ps.setInt(1, id);
            return ps.executeUpdate() > 0;      //若删除成功，返回true
        }
    }
    //查
    public static List<Student> getAllStudents(Connection connection) throws SQLException {
        List<Student> students = new ArrayList<>();     //创建一个学生列表
        String query = "SELECT id, name, age, major FROM students";
        try (PreparedStatement ps = connection.prepareStatement(query); ResultSet rs = ps.executeQuery()) { //用ResultSet来遍历数据库返回的记录
            while (rs.next()) {             //把数据库中查询到的信息转化为Student对象，加入列表
                students.add(new Student(
                        rs.getInt("id"),
                        rs.getString("name"),
                        rs.getInt("age"),
                        rs.getString("major")
                ));
            }
        }
        return students;        //返回Student对象（包含所有学生信息）
    }
    //改
    public static boolean updateStudent(Connection connection, Student student) throws SQLException {
        String query = "UPDATE students SET name = ?, age = ?, major = ? WHERE id = ?";     //根据id更新学生
        try (PreparedStatement ps = connection.prepareStatement(query)) {
            ps.setString(1, student.getName());
            ps.setInt(2, student.getAge());
            ps.setString(3, student.getMajor());
            ps.setInt(4, student.getId());
            return ps.executeUpdate() > 0;      //更新成功返回true
        }
    }
}
```

### 2.3 StudentController.java
这是整个项目最核心的类，作为**REST API控制器**，连接前端和数据库。

- 首先导入几个包，
- 注解@RestController，等于 `@Controller` + `@ResponseBody`两个注解组合；`@Controller`：标记这是一个Spring MVC控制器，会被Spring容器管理，`@ResponseBody`：表示方法返回值直接作为HTTP响应体（自动转JSON），而不是视图名。
- 注解@RequestMapping("/api/students")，定义这个控制器的**基础URL路径**，该控制器所有方法的URL都以 `/api/students` 开头，例如：GET `/api/students` 获取所有学生。
- 注解@CrossOrigin(origins = "*")，解决**跨域问题**，因为前端服务器和后端服务器可能在不同的端口，浏览器默认会阻止，`origins = "*"` 表示允许来自任何域的请求访问，可以解决这个问题。
- 注解@GetMapping，标记这个方法处理 **HTTP GET 请求**，相当于 `@RequestMapping(method = RequestMethod.GET)`；
- 其余的如@PostMapping注解，类似的表示标记这个方法处理 **HTTP GET 请求**；以添加学生为例，当用户在前端页面点击“添加学生”按钮，前端由JS事件监听器'submit'定位到handleFormSubmit方法，接着验证表单，由addStudent接受StudentData数据，发送POST请求给后端；请求到达服务器后，Spring Boot框架会进行路由匹配：由注解@RestController找到RESTAPI控制器；由注解@RequestMapping让spring知道所有以这个URL路径开头的请求都由这个类处理；因为请求是 POST /api/students，Spring会匹配到@PostMapping，由这个addStudent方法参数验证没问题后，会通过Connection conn = DatabaseConnector.getConnection()获取数据库连接；接着创建Studnet对象，调用Studnet类的静态方法将学生插入；最后调用辅助方法createSuccessResponse()创建响应体，Spring会自动把Map序列化为JSON,最后由前端处理响应，返回给客户端。


### 2.3.1 代码演示

```java
package com.studentmanagement.controller;           //StudentController.java

import com.studentmanagement.Student;
import com.studentmanagement.DatabaseConnector;
import org.springframework.http.ResponseEntity;             //这个包用于构建HTTP响应
import org.springframework.web.bind.annotation.*;           //这个包包含了处理HTTP请求的注解，如RestController, GetMapping等

import java.sql.Connection;
import java.sql.SQLException;
import java.util.HashMap;                                   //这个包用于创建HashMap数据结构
import java.util.List;                                      //这个包用于处理List数据结构
import java.util.Map;                                       //这个包用于处理Map数据结构

/**
 * 学生管理 REST API 控制器
 * 提供学生的增删改查接口
 */
@RestController                             //RestController注解表示这是一个控制器类，负责处理HTTP请求并返回响应体
@RequestMapping("/api/students")        //requestMapping注解定义了该控制器处理的基础URL路径
@CrossOrigin(origins = "*")               //允许跨域请求，允许来自任何来源的请求访问该控制器的接口
public class StudentController {         //StudentController类，处理与学生相关的HTTP请求

    /**
     * 获取所有学生列表
     * GET /api/students
     */
    @GetMapping                                                           //GetMapping注解表示该方法处理HTTP GET请求
    public ResponseEntity<?> getAllStudents() {                             //ResponseEntity<?>表示返回任意类型的响应体,?表示响应体可以是任意类型
        try (Connection conn = DatabaseConnector.getConnection()) {        //这里使用try-with-resources语法，确保数据库连接在使用后自动关闭
            List<Student> students = Student.getAllStudents(conn);        //调用Student类的静态方法getAllStudents获取所有学生列表
            return ResponseEntity.ok(students);                          //返回200 OK响应，响应体是学生列表
        } catch (SQLException e) {
            return ResponseEntity.status(500).body(createErrorResponse("获取学生列表失败：" + e.getMessage()));      //发生异常时，返回500错误响应，响应体包含错误信息
        }
    }

    /**
     * 添加新学生
     * POST /api/students
     */
    @PostMapping                                                                                       //PostMapping注解表示该方法处理HTTP POST请求
    public ResponseEntity<?> addStudent(@RequestBody StudentRequest request) {                           //@RequestBody注解表示请求体会被反序列化为StudentRequest对象
        // 参数验证
        if (request.getName() == null || request.getName().trim().isEmpty()) {                           //如果姓名为空，返回400错误响应
            return ResponseEntity.badRequest().body(createErrorResponse("姓名不能为空"));                  //返回错误响应体
        }
        if (request.getAge() == null || request.getAge() <= 0) {                                        //如果年龄不是正整数，返回400错误响应
            return ResponseEntity.badRequest().body(createErrorResponse("年龄必须是正整数"));              //返回错误响应体
        }
        if (request.getMajor() == null || request.getMajor().trim().isEmpty()) {                       //如果专业为空，返回400错误响应
            return ResponseEntity.badRequest().body(createErrorResponse("专业不能为空"));                //返回错误响应体
        }

        try (Connection conn = DatabaseConnector.getConnection()) {                                                        //这里使用try-with-resources语法，确保数据库连接在使用后自动关闭
            Student student = new Student(0, request.getName().trim(), request.getAge(), request.getMajor().trim());   //创建新的学生对象
            Student.insertStudent(conn, student);                                                                        //调用Student类的静态方法insertStudent将学生添加到数据库
            return ResponseEntity.ok(createSuccessResponse("学生添加成功"));                                               //返回200 OK响应，响应体包含成功信息
        } catch (SQLException e) {
            return ResponseEntity.status(500).body(createErrorResponse("添加学生失败：" + e.getMessage()));               //返回500错误响应，响应体包含错误信息
        }
    }

    /**
     * 更新学生信息
     * PUT /api/students/{id}
     */
    @PutMapping("/{id}")                                                                                    //PutMapping注解表示该方法处理HTTP PUT请求，{id}是路径变量
    public ResponseEntity<?> updateStudent(@PathVariable int id, @RequestBody StudentRequest request) {       //@PathVariable注解表示从URL路径中提取id参数，@RequestBody注解表示请求体会被反序列化为StudentRequest对象
        // 参数验证
        if (request.getName() == null || request.getName().trim().isEmpty()) {                              //如果姓名为空，返回400错误响应
            return ResponseEntity.badRequest().body(createErrorResponse("姓名不能为空"));
        }
        if (request.getAge() == null || request.getAge() <= 0) {                                           //如果年龄不是正整数，返回400错误响应
            return ResponseEntity.badRequest().body(createErrorResponse("年龄必须是正整数"));
        }
        if (request.getMajor() == null || request.getMajor().trim().isEmpty()) {                          //如果专业为空，返回400错误响应
            return ResponseEntity.badRequest().body(createErrorResponse("专业不能为空"));
        }

        try (Connection conn = DatabaseConnector.getConnection()) {                                      //这里使用try-with-resources语法，确保数据库连接在使用后自动关闭
            Student student = new Student(id, request.getName().trim(), request.getAge(), request.getMajor().trim());
            boolean success = Student.updateStudent(conn, student);                                     //调用Student类的静态方法updateStudent更新学生信息
            if (success) {
                return ResponseEntity.ok(createSuccessResponse("学生信息更新成功"));                       //返回200 OK响应，响应体包含成功信息
            } else {
                return ResponseEntity.status(404).body(createErrorResponse("未找到该学生"));              //返回404错误响应，响应体包含错误信息
            }
        } catch (SQLException e) {
            return ResponseEntity.status(500).body(createErrorResponse("更新学生失败：" + e.getMessage()));    //返回500错误响应，响应体包含错误信息
        }
    }

    /**
     * 删除学生
     * DELETE /api/students/{id}
     */
    @DeleteMapping("/{id}")                                                                                //DeleteMapping注解表示该方法处理HTTP DELETE请求，{id}是路径变量
    public ResponseEntity<?> deleteStudent(@PathVariable int id) {                                           //@PathVariable注解表示从URL路径中提取id参数
        try (Connection conn = DatabaseConnector.getConnection()) {                                         //这里使用try-with-resources语法，确保数据库连接在使用后自动关闭
            boolean success = Student.deleteStudentById(conn, id);
            if (success) {
                return ResponseEntity.ok(createSuccessResponse("学生删除成功"));                              //返回200 OK响应，响应体包含成功信息
            } else {
                return ResponseEntity.status(404).body(createErrorResponse("未找到该学生"));                  //返回404错误响应，响应体包含错误信息
            }
        } catch (SQLException e) {
            return ResponseEntity.status(500).body(createErrorResponse("删除学生失败：" + e.getMessage()));   //返回500错误响应，响应体包含错误信息
        }
    }

    /**
     * 创建成功响应
     */
    private Map<String, Object> createSuccessResponse(String message) {             //创建一个Map作为响应体，包含success和message字段
        Map<String, Object> response = new HashMap<>();                             //创建一个HashMap实例
        response.put("success", true);                                              //设置success字段为true
        response.put("message", message);                                           //设置message字段为传入的消息
        return response;                                                            //返回响应体
    }

    /**
     * 创建错误响应
     */
    private Map<String, Object> createErrorResponse(String message) {               //创建一个Map作为响应体，包含success和message字段
        Map<String, Object> response = new HashMap<>();
        response.put("success", false);                                             //设置success字段为false
        response.put("message", message);                                           //设置message字段为传入的消息
        return response;
    }

    /**
     * 学生请求体类
     */
    public static class StudentRequest {                                            //StudentRequest类，表示添加或更新学生时的请求体
        private String name;
        private Integer age;
        private String major;

        public String getName() { return name; }                                    //这个方法用于获取name属性值
        public void setName(String name) { this.name = name; }                      //这个方法用于设置name属性值
        public Integer getAge() { return age; }
        public void setAge(Integer age) { this.age = age; }
        public String getMajor() { return major; }
        public void setMajor(String major) { this.major = major; }
    }
}
```

```JavaScript
        });

        const result = await response.json();                       // 解析响应为JSON格式

        if (response.ok && result.success) {                        // 检查响应状态和结果
```

### 关于JDBC
- 详细总结Connection类在JDBC中扮演什么角色？
Connection是JDBC中最核心的接口之一，它代表Java程序与数据库之间的一条通信通道。(StudentController类 第31行，conn就是“通道”，通过conn对象，Java就可以向数据库发送SQL并获取结果)

Connection的主要职责：
1. **建立连接** -> 与数据库服务器建立TCP连接 -> DriverManager.getConnection()
2. **创建语句对象** -> 生成执行SQL的Statement或PreparedStatement -> conn.prepareStatement(sql)
3. **事务管理** -> 控制事务的提交和回滚 -> setAutoCommit(), commit(), rollback()
4. **资源释放** -> 关闭连接，释放数据库资源 -> close()


- getConnection()方法在JDBC中扮演什么角色？
getConnection()是获取数据库连接的入口方法，它负责根据提供的信息建立与数据库的连接。

- PreparedStatement和Statement的区别？
**Statement**：SQL编写用拼接字符串；SQL注入有风险；每次都要重新编译；可读性差；
**PreparedStatement**：SQL编写使用?占位符；SQL注入安全；预编译，可复用；可读性好；
